# IP, scope and honesty notes

* **No proprietary fuel data.** The HERRSCHER proprietary gaseous fuel/blend is *not* represented. Fuel-property variability is represented by an H2-CH4 surrogate family. Composition, formulation, calibration data and component-level material allocations are not in this repository and can be shared only under a confidentiality framework (see the two concept notes, Table 5 and Section 5).
* **No hardware results.** HERRSCHER has not validated, tested, certified, manufactured or demonstrated a gas-turbine retrofit. The experimental programme so far concerns reciprocating IC-engine platforms; that work gives context, not validation, for the gas-turbine concepts.
* **Generic platform.** The reference machine (about 5 MW class, PR 12, 20 kg/s) is assumed and is not any OEM's turbine. Platform selection is gate G1.
* **Collaboration status.** The architecture and materials concept notes were prepared for technical discussion with CSIR-NAL; the repository claims no endorsement or review outcome. Materials work (hydrogen-embrittlement screening, coatings) is planned with CSIR laboratories, partner to be confirmed.
* **Standards.** ISO 21789, API 616, ASME B31.12, NFPA 2, IS/IEC 60079 are candidate frameworks; no compliance is claimed.
